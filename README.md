# Смута 2.0

Наша команда представляет Смуту 2.0. Мы учли ошибки нашей предыдущей игры и уменьшили наши амбиции, чтобы эта задача была полностью вывполнена нашей. Игра рассчитана на 1 до 4 человек и работает через системы лобби: В начале один из игроков становится хостом для всех других: он создаёт лобби, к которому будут подключаться все остальные игроки по коду, которые будет сгенерирован для хоста, как только лобби будет полностью создано. Далее игроки получают этот код и подключаются по нему в лобби, где выбирают команду, за которую они будут играть. На выбор есть 4 комнды: 2-е Ополчение/Минин и Пожарский(Красные), Шведы/князь Шуйский(Синие), Речь Посполитая/Лжедмитрий 2(Жёлтые) и Казаки/Болотников(Зелёные). Все личности и их стороны достоверны и выверены по секретным документам. Псоле выбора всеми игроками команд, хотс нажимает на кнопку и запускает игру всем участникам. Сама игра происходит на карте России времён смутного времени. Каждая сторона спавниться в стартовом городе в зависимости от выбора команды. Основная цель на игру - захват Москвы и её удержание в течении определённого времени. За каждые 5 секунд удержания города игроку выдаётся очко. При наборе 5 очков игрок побеждает и подсчёт очков останавливается. Но всё не так просто. Саму Москву обороняют бояре при Иване Грозном, не хотевшие отдавать власть в другие руки, тоэтому, прежде чем захватить Москву, её нужно отбить у них. Предуреждение: за коренных москвичей в 3 поколении играть нельзя!
